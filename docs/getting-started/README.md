# Getting started

Install M5Unified and its M5GFX dependency for your Arduino or ESP-IDF project.
Choose the target board, then open a complete example directory.

Use `M5.config()` to select features, `M5.begin(cfg)` to initialize hardware,
and call `M5.update()` regularly for buttons and touch. Check device capabilities
before using optional hardware.

Start with [HowToUse](../../examples/Basic/HowToUse), or the
[example index](../examples/README.md) for a focused task.
